## Selected Projects

- **[Active Noise Control with Neural Networks](https://github.com/PanosLelakis/ANC-with-NN)**  
  Diploma thesis: a Python simulation framework comparing adaptive ANC algorithms with a convolutional recurrent neural network, including automated experiments and performance evaluation.

- **[Automatic Headphone Equalization](https://github.com/PanosLelakis/Headphone-EQ-Auto)**  
  Headphone equalization in Python, featuring a custom algorithm for automatically determining filter parameters to approximate a target frequency response.

- **[Eternity II Puzzle Solver](https://github.com/PanosLelakis/EII-MILP-solver)**  
  Puzzle solver using a binary mixed-integer linear programming model with PuLP/CBC and a Tkinter interface for loading puzzles and displaying solutions.

- **[Santokriti](https://github.com/PanosLelakis/Santokriti)**  
  University team project: a full-stack tourist guide website using Node.js, Express, Handlebars and PostgreSQL. My contribution focused mainly on backend development.
